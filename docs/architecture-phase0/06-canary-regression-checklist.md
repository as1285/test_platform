# 金丝雀账号回归清单

> 每次阶段 1+ 后端/前端核心发版前，用**固定测试账号**跑一遍。  
> 建议准备：未激活号 ×1、已激活号 ×1、游客/商用各视需要。

## 账号准备

| 角色 | 用途 | 备注 |
|------|------|------|
| Canary-A | 未激活 | 可写演示税、看水印 |
| Canary-B | 已激活 | 完整能力 |
| Canary-Admin | 管理端 | 仅内网/受信环境 |

（具体用户名写入运维私密备忘，**勿提交真实密码到 git**。）

## 清单（打勾）

### A. 鉴权

- [ ] A1 注册新号成功（或使用预置 Canary）
- [ ] A2 登录成功，进入「我的」
- [ ] A3 退出后再登录
- [ ] A4 错误密码有限流/提示，不 500

### B. 激活

- [ ] B1 Canary-A 用测试激活码激活成功
- [ ] B2 激活后水印消失 / `account_active` 正确
- [ ] B3 管理台能看到该用户激活状态
- [ ] B4（可选）支付宝下单创建订单成功（沙箱/小额）

### C. 税务

- [ ] C1 咨询页「示例填写」或粘贴导入解析预览成功（见 v0721 文案）
- [ ] C2 一键生成税务记录，条数符合预期
- [ ] C3 收入纳税明细 / 详情页能打开且金额合理
- [ ] C4 按公司删除 → 回收站可见 → 恢复成功
- [ ] C5 批量修改覆盖不把其它公司数据误删

### D. 资料

- [ ] D1 个人信息改姓名/证件保存成功
- [ ] D2 添加任职受雇
- [ ] D3 粘贴导入个人信息（姓名手机证件地址银行卡）写入成功
- [ ] D4 银行卡列表展示

### E. 增长（抽检）

- [ ] E1 打开安装页，管理台安装统计有浏览增量（或埋点表有事件）
- [ ] E2 下载按钮可点（链接有效）

### F. 管理台

- [ ] F1 管理员登录
- [ ] F2 发码成功
- [ ] F3 接口统计页可打开
- [ ] F4 转化分析页可打开

### G. 壳（若发 APK）

- [ ] G1 Cordova 打开为 `geshui.vip` 而非第三方站
- [ ] G2 外链（支付宝）走系统浏览器/Intent，不整页变成陌生域名
