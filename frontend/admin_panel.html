增长与触达配置

优先配置定价实验；下方为弹窗与 QQ / 微信触达入口。效果请到「转化与触达」查看。

定价/支付页 A/B/C

统一控制支付页与落地页分流（改占比只影响新访客，已分配用户锁定不变）。 A：支付宝仅「199 永久」+ 其它渠道 + 激活码（落地页 B）； B：支付宝多档价，收起其它渠道（落地页 B）； C：下载 App + 激活码 +「联系方式配置」中的专属客服（落地页游客沙盒；无支付宝/其它购买渠道）。 A+B+C 必须为 100%。

A 50% · B 50% · C 0%

未激活引导弹窗

对未激活用户在 App 内弹出引导（默认每日最多 1 次）。关闭后当日不再弹出；可配置注册满多少小时后才提示。

QQ 添加链接（个人中心顶栏）

用户在「我要咨询 / 个人中心」页顶栏点击「添加QQ号」时打开此链接（如 QQ 好友加号页，须为 https 完整地址）。留空并保存则点击时提示未配置。

微信收款码（用户反馈页）

上传后将在用户端「购买激活」页与「我要咨询 → 我要反馈」展示。支持本地上传（写入 uploads/）或填写 uploads/… / https 图片地址；留空并保存则不显示。

联系方式配置

仅在支付页 C 方案展示（下载 App + 激活码旁的专属客服卡片）。A/B 方案购买页不展示此处配置。

引导安装（用户端）

用户打开的页面为「安装包和使用方法」（在新标签预览）与「操作教程」（在新标签预览）。下方可配置安装包下载、引导视频与首屏效果预览（动图 + 截图横滑）；其它界面配图仍在左侧「用户端外观」。

落地页 B/C（跟随支付页 A/B/C）

分流已统一到左侧「增长与触达配置 → 定价/支付页 A/B/C」。支付页 C 同时进入落地页游客沙盒；A/B 走迷你产品首页。此处不再单独配置流量占比，避免两套打架。C 方案购买页展示「下载 App」「激活码」以及「联系方式配置」中的专属客服。

安装包下载（用户端）

用户在「安装包和使用方法」页只看到下载按钮。推荐在此本地上传安装包（写入站点 uploads/）；也可手填外链（安卓须 https 完整 URL）或站内路径（苹果如 /personal.mobileconfig）。留空则对应按钮不显示。

用 scripts/build-agent-apk.sh 渠道ID 打包后上传此处。用户从代理推广链接（?ch=渠道ID 且在上方隐藏闲鱼列表中）进入安装页时，将下载此包而非普通 APK；也可直接发给客户安装。

用户在「我的」点「激活」进入购买页后，点击「闲鱼购买」会复制此处全文到剪贴板。

给代理的推广链接带上 ?ch=渠道ID（如 install_guide.html?ch=agent_zhang 或 register.html?ch=agent_zhang）。用户从该链接进入后，即使下载 App 再打开，系统也会按设备自动恢复渠道 ID（48 小时内同 IP 有效）；你自己引流的普通链接不带 ch，仍显示闲鱼入口。

安装引导视频

对应用户页「安装包和使用方法」中的两个视频位，以及 C 端「操作教程」页；支持相对路径、uploads/xxx.mp4 或完整 https 链接，也可本地上传到 uploads/。
