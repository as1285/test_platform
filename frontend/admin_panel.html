系统设置

QQ 添加链接（个人中心顶栏）

用户在「我要咨询 / 个人中心」页顶栏点击「添加QQ号」时打开此链接（如 QQ 好友加号页，须为 https 完整地址）。留空并保存则点击时提示未配置。

QQ 用户交流群链接

用户在激活成功、填完个税、消息中心、帮助页等场景点击「加入用户交流群」时打开此链接（QQ 加群页，须为 https）。留空则相关入口不展示或点击时提示未配置。

微信收款码（用户反馈页）

上传后将在用户端「我要咨询 → 我要反馈」页面展示。支持本地上传（写入 uploads/）或填写 uploads/… / https 图片地址；留空并保存则不在用户端显示。

转化 A/B 配置

控制用户端激活弹窗文案与税务记录页「30秒体验」按钮。用户按账号哈希分配 A/B 变体，可在接口统计中查看 track_conversion_ab_variant。

引导安装（用户端）

用户打开的页面为「安装包和使用方法」（在新标签预览）与「操作教程」（在新标签预览）。下方可配置安装包下载、引导视频与首屏效果预览（动图 + 截图横滑）；其它界面配图仍在左侧「用户端外观」。

安装包下载（用户端）

用户在「安装包和使用方法」页只看到下载按钮。推荐在此本地上传安装包（写入站点 uploads/）；也可手填外链（安卓须 https 完整 URL）或站内路径（苹果如 /personal.mobileconfig）。留空则对应按钮不显示。

用 scripts/build-agent-apk.sh 渠道ID 打包后上传此处。用户从代理推广链接（?ch=渠道ID 且在上方隐藏闲鱼列表中）进入安装页时，将下载此包而非普通 APK；也可直接发给客户安装。

用户在个人中心点「激活」时的弹窗中点击「闲鱼购买」会复制此处全文到剪贴板。

给代理的推广链接带上 ?ch=渠道ID（如 install_guide.html?ch=agent_zhang 或 register.html?ch=agent_zhang）。用户从该链接进入后，即使下载 App 再打开，系统也会按设备自动恢复渠道 ID（48 小时内同 IP 有效）；你自己引流的普通链接不带 ch，仍显示闲鱼入口。

安装引导视频

对应用户页「安装包和使用方法」中的两个视频位，以及 C 端「操作教程」页；支持相对路径、uploads/xxx.mp4 或完整 https 链接，也可本地上传到 uploads/。

安装页效果预览

在「安装包和使用方法」页首屏展示个税明细效果：1 张动图（GIF/WebP 自动循环）+ 最多 3 张静图横滑（明细 / 申报 / 税记录）。支持 uploads/ 相对路径或 https 外链；留空则不显示对应位。

动图建议宽度 750px、≤2MB；静图建议手机截图比例。保存方式与上方「保存引导安装配置」相同。
