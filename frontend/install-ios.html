选择一种方式完成安装

两种方式任选其一即可

新机必看（iPhone 16 / 17 等 iOS 18+） 添加时若未打开 「以 Web App 形式打开」，从主屏幕进会仍显示 Safari 地址栏和底栏（像浏览器）。 出现这种情况：先删掉主屏幕旧图标，再按下面步骤重装，并确认该开关为开启。
  1. 确认使用的是iOS自带浏览器(Safari)，不要用微信/Chrome 内置浏览器
  2. 点击浏览器底部 「分享/共享 按钮」（方形+向上箭头图标）
  3. 若标签页布局为顶部/底部，先点更多选项（三个点）
  4. 向下滚动共享菜单，找到并点击 「添加到主屏幕」
  5. 自定义APP名称，可预览图标
  6. 添加确认页务必打开 「以 Web App 形式打开」（开关为绿色/开启）。关掉则会带地址栏
  7. 点击 「添加」，图标出现在主屏幕后，必须点主屏幕图标打开（不要再从 Safari 历史记录进）

正确安装后应无地址栏、无 Safari 底栏。若仍有地址栏，说明未以 Web App 打开，请删除图标后重装。

下载并安装描述文件后，主屏幕会出现应用图标，点开即可使用。

正在获取描述文件…
  1. 点击上方按钮下载 描述文件
  2. 按系统提示允许下载，打开 「设置」
  3. 顶部出现已下载描述文件时，点进去 安装
  4. 按提示输入密码完成安装，回到主屏幕打开图标

若按钮不可用，请稍后再试或改用「分享到主屏幕」。
